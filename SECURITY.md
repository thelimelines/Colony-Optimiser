# Security policy

## Supported releases

Security fixes are made against the latest published release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** form on this repository's [Security advisories page](../../security/advisories/new). Include a clear description, the affected version, and steps to reproduce. Do not include Colony Survival save files, personal paths, or private game data unless a maintainer requests them through the private advisory.

## Download safety

Official application downloads are published only through this repository's Releases page. Every release asset has a companion SHA-256 checksum file, and verification is recommended before running the application. Release binaries are not code-signed yet, so do not override Windows warnings for files obtained from any other source.
